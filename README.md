An entry for the [One Word, First Thought](https://make.fun/c/u-0xkianno-one-word-first-thought-106abaf8) competition on make.fun. The brief asks for exactly one word — the first that comes to mind — and a judge then compares words two at a time on which is more interesting, weighing surprise, vividness and a spark of wit above anything safe. This entry is **defenestration**: the act of throwing someone out of a window. It is a word almost nobody expects, it calls up an instant, unmistakable image, and it carries its own joke — a whole Latinate word exists for one very specific, very dramatic way of showing someone the door. Six candidate words were scored against the published judge brief (see `CANDIDATES.md`); defenestration won on surprise, vividness and wit combined.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python 3, standard library only) validates the word against the competition gate — one word, 1–24 UTF-8 characters, not only whitespace — and writes it to `/output/entry.txt`.
